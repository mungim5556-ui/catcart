# 🐱 CatCart

고양이들이 달리는 귀여운 로우폴리 3D 카트 레이싱 게임 (웹 브라우저용).

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:5173 에서 플레이
npm run build    # dist/ 에 배포용 빌드
```

## 조작법

| 키 | 동작 |
|---|---|
| `W` / `↑` | 가속 |
| `S` / `↓` | 브레이크 · 후진 |
| `A` `D` / `←` `→` | 조향 |
| `Space` / `Shift` (누른 채로 꺾기) | 점프 → 드리프트 |
| `E` / `Ctrl` | 아이템 사용 |
| `R` | 도로로 복귀 |
| `Esc` / `P` | 일시정지 |
| `M` | 소리 켜기/끄기 |
| `H` | 도움말 켜기/끄기 |
| `Enter` / `Esc` | (완주 후) 다시 달리기 / 메인 메뉴 |

드리프트를 유지하면 불꽃 색이 **파랑 → 주황 → 보라**로 바뀌고, 버튼을 떼면 단계별 터보가 발동합니다.
**게임 흐름:** 타이틀 → 모드(🏁 레이스 / 🏆 냥냥컵) → 고양이 선택(치즈, 까망이, 설기, 고등어, 삼색이, 샴 중 하나 · 나머지는 AI 라이벌) · 난이도(쉬움 50cc / 보통 100cc / 어려움 150cc) → (레이스) 트랙 선택 → 3바퀴 레이스!

**트랙:** 🌼 냥냥 초원 · 🏖️ 참치 해변 · ❄️ 눈꽃 마을 — 최고 기록은 트랙마다 따로 저장됩니다.

**🏆 냥냥컵:** 세 트랙을 연달아 달리고 순위 점수(1위 10 · 7 · 5 · 3 · 2 · 1점)를 합산해 우승자를 가립니다.
고른 고양이와 난이도는 다음에도 기억됩니다. 레이스 중 다른 탭으로 가면 자동으로 일시정지돼요. 카운트다운 **1**이 나올 때 가속하면 🚀 로켓 스타트!
최고 기록과 최고 랩은 브라우저에 저장됩니다.

**아이템:** 도로 위 무지개 ❓ 상자를 지나가면 아이템 룰렛이 돌아갑니다 (순위가 낮을수록 좋은 아이템).

| 아이템 | 효과 |
|---|---|
| 🐟 생선 부스트 | 순간 가속 |
| 🧶 털실 뭉치 | 앞으로 굴러가 바로 앞 순위 카트를 추적해서 맞힘 |
| 🍌 바나나 | 뒤에 설치 — 밟으면 한 바퀴 빙글! |

게임패드도 지원합니다 (스틱 조향, RT 가속, LT 브레이크, RB 드리프트, X 아이템).

## 폴더 구조

```
src/
├── main.ts              # 게임 루프 (고정 60Hz 물리 + 보간 렌더링)
├── core/input.ts        # 키보드/게임패드 입력
├── core/chaseCamera.ts  # 3인칭 추적 카메라
├── kart/kartPhysics.ts  # 아케이드 카트 물리 + 드리프트/미니터보 (튜닝값: KART)
├── kart/catKart.ts      # 로우폴리 고양이 카트 모델 + 연출, 고양이 목록(ROSTER)
├── world/trackDefs.ts   # 트랙 목록: 모양 · 부스트/점프대/아이템 위치 · 테마 색 · 풍경 구성
├── world/track.ts       # 트랙 정의로 도로 · 지형 · 풍경을 만들고 충돌/높이 계산
├── world/scenery.ts     # 풍경 소품 (나무, 야자수, 파라솔, 모래성, 눈사람, 선물상자 …)
├── race/lapTracker.ts   # 체크포인트 · 랩 카운트 · 역주행 감지 (AI에도 재사용)
├── race/raceSession.ts  # 카운트다운 → 레이스 → 완주, 로켓 스타트, 기록 저장
├── race/racer.ts        # 레이서 1명 (물리+모델+랩 추적+AI) · 카트끼리 충돌
├── ai/aiDriver.ts       # AI 주행: 라인 추종, 추월, 드리프트, 바나나 피하기, 복귀
├── items/items.ts       # 아이템 상자 · 룰렛 확률 · 털실/바나나 · AI 아이템 사용 타이밍
├── audio/audio.ts       # 효과음 · 엔진 · 배경음악 (Web Audio로 전부 코드 합성, 음원 파일 없음)
├── fx/sparks.ts         # 드리프트 불꽃/먼지/색종이 파티클
├── fx/skidMarks.ts      # 드리프트 타이어 자국
├── fx/snowfall.ts       # 눈 내리는 효과 (눈꽃 마을)
├── ui/hud.ts            # 속도계, 드리프트 게이지, 배너
├── ui/menus.ts          # 타이틀 · 조작법 · 고양이 선택 · 난이도 · 일시정지 메뉴
├── ui/raceHud.ts        # 랩/타이머, 카운트다운, 미니맵, 결과 화면
├── ui/itemHud.ts        # 아이템 슬롯 · 룰렛 연출
└── ui/trackPreview.ts   # 트랙 선택 화면의 트랙 모양 미리보기
tools/analyze-track.mjs  # 새 트랙 모양 검사 (커브 반지름 · 도로끼리 간격 · 직선 구간)
```

AI 성격(속도·드리프트·로켓 스타트)은 `src/kart/catKart.ts`의 `ROSTER`, 난이도별 배율은 `src/ui/menus.ts`의 `DIFFICULTIES`에서 조절합니다.
조작감 튜닝은 `src/kart/kartPhysics.ts`의 `KART` 값을 바꾸면 됩니다.
브라우저 콘솔에서 `catcart.KART.maxSpeed = 30`처럼 실시간으로 바꿔 볼 수도 있어요.

## 새 트랙 추가하기

1. `src/world/trackDefs.ts`의 `TRACKS`에 트랙을 하나 더 적습니다 (`points`는 도로 중심선의 점들).
2. 모양을 검사합니다:
   ```bash
   node tools/analyze-track.mjs '{"mytrack":[[0,-100],[80,-90], ...]}'
   ```
   가장 급한 커브 반지름은 **17m 이상**, 도로끼리 간격(self-clearance)은 **30m 이상**이 좋습니다.
   출력되는 직선 구간(straights)에 부스트 패드(`pads`)와 점프대(`ramps`)를 놓으세요.
